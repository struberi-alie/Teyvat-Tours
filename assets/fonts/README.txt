Font files are intentionally not bundled in this generated project.
If you want fully offline typography, copy your own originals into this folder using these filenames:
- DMSans-Regular.ttf
- CrimsonText-Regular.ttf
- BirthstoneBounce-Regular.ttf
- BirthstoneBounce-Medium.ttf
- Scintilla-3z7rG.otf
- zhcn.ttf
- MilknBalls-BlackDemo.otf

The CSS already contains @font-face declarations for those paths and also loads close Google Fonts fallbacks when internet access is available.
